# Contributing to Elixpo Open Source

Start with an issue or an Elixpo Discussion before undertaking a large change. Keep pull requests focused, explain the user-visible result, and run the commands declared in `.elixpo/project.yml`. The [README warm-up](README.md#warm-up-no-keys) lists the same commands CI runs (`npm ci`, `./biome.sh ci`, `npm test`, `npm run build`); none of them needs keys. By participating, you agree to the repository's code of conduct.

- Issues: https://github.com/elixpo/opensource.elixpo/issues
- Discussions: https://github.com/orgs/elixpo/discussions
